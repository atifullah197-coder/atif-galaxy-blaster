# 🎮 Atif Galaxy Blaster — Ultimate Edition

A self-contained HTML5 canvas space shooter: fast waves of enemies, boss fights, power-ups and shields — all in a single `index.html` file, no build step and no dependencies.

## ▶️ Play it live

https://atif-galaxy-blaster.vercel.app

## ✨ Features

- Wave-based enemy combat with escalating difficulty
- Boss fights
- Power-ups and shield pickups
- Score and lives system with game-over / restart flow
- Keyboard controls, smooth canvas animation
- Works in any modern browser — just open the page and play

## 🛠️ Tech

- HTML5 Canvas
- Vanilla JavaScript
- CSS
